# First-use fixture

This directory is a disposable, public test project for the
[volunteer trial kit](../../docs/volunteer-trial-kit.md). Copy it outside the Boron Context checkout
and initialize the copy as a new Git repository before use.

The fixture deliberately contains only three project facts and ignores generated exports. Do not add
personal information, private project material, credentials, or production data. Keep task outputs
and the private validation receipt outside the Boron Context repository.
