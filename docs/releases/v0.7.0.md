# Boron Context v0.7.0 — Spatial project memory

Version 0.7.0 turns the local Boron Content Inspector into a spatial, progressively disclosed
project workbench while preserving Boron's read-only review and provenance boundaries.

## What changed

- `/inspector/spatial` renders Ontology entities and a bounded live Codebase Memory projection with
  a local, pinned Three.js dependency and no CDN.
- L0 shows project and architecture clusters, L1 reveals representative symbols for one cluster,
  and L2 queries only the selected symbol's one-hop callers and callees. The projection contains
  names and typed derived edges, not source files, repository text, or local file paths.
- Desktop pointer input and Quest WebXR controller/pinch input share the same drill-down model.
  Two-hand input scales and rotates the graph; breadcrumbs and back navigation restore higher
  levels.
- Cinematic FX adds hologram shells, curved energy links, directional particles, reveal transitions,
  orbiters, and selection shockwaves. Quest performance mode reduces decorative work without
  changing graph data or permissions.
- The optional LAN MR gateway binds one explicit private IPv4 and keeps the privileged daemon on
  `127.0.0.1:41635`. A separate HTTP bootstrap exposes only health and the local CA certificate;
  the HTTPS surface requires a single-use pairing code and exposes only the spatial shell, local
  Three.js assets, Ontology reads, and bounded Codebase reads.
- An ADB reverse workflow remains available as a development fallback without opening any LAN
  listener on the daemon.

## Trust boundary

The first certificate download is intentionally separated from the HTTPS data surface. Before
installing the local CA on a Quest, compare the SHA-256 fingerprint displayed by the bootstrap page
with the value printed directly on the Mac by:

```bash
boron-context lan-inspector pair
```

Stop if the values differ. The CA private key and pairing/session secrets remain in the Mac state
directory with mode `0600`. Pairing codes expire after five minutes, are consumed once, and rotate
immediately after a successful exchange. Paired sessions are bound to the client address and expire
after eight hours. The LAN process has no route capable of recording an activity, resolving a
correction, or changing project state.

## Verification

- TypeScript typecheck, Vitest, production build, Prettier, diff checks, and production dependency
  audit;
- TLS certificate generation, visible CA fingerprint, single-use pairing, rate/size boundaries,
  read allowlist, and write rejection;
- deterministic L0/L1/L2 graph bounds and omission of source contents and local paths;
- desktop rendering and drill-down with live FPS/draw-call telemetry;
- macOS launchd generation plus Swift menu-bar tests and release build;
- PostgreSQL integration on the release branch.

Boron Context remains pre-alpha. Quest browser and hand-tracking behavior can vary across Meta
Browser/runtime releases; the data and authorization boundaries do not depend on gesture support.
