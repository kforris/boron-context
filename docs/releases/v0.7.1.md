# Boron Context v0.7.1 — Reliable LAN MR startup

Version 0.7.1 is a focused reliability patch for the v0.7 spatial release.

When macOS starts or restarts the loopback daemon and the separate LAN MR companion together,
launchd can schedule the companion before port `41635` is ready. The companion now performs a
bounded health retry before binding its read-only LAN ports. It still fails closed if the daemon
does not become healthy, and it never retries pairing exchanges or user requests implicitly.

## Verification

- deterministic test covering two transient connection failures followed by daemon readiness;
- full TypeScript typecheck, Vitest suite, production build, formatting, and dependency audit;
- PostgreSQL integration and macOS menu-bar checks remain unchanged from v0.7.0.
