# Boron Context v0.7.5 — Held-out continuity regression gate

Version 0.7.5 introduces the first repeatable offline evaluation boundary for macOS + Codex
continuity. It remains a productization milestone and does not authorize public release,
Marketplace submission, paid activity, or marketing.

## Evaluation contract

- versioned, synthetic, secret-free fixtures exercise continuity resume, telemetry intent,
  high-risk policy routing, source anchors, and post-upgrade health retrieval;
- the deterministic runner reports recall@5, mean reciprocal rank, relevant fixture source
  coverage, failure categories, and Boron-owned LLM calls;
- the same production project-scope guard is exercised for accepted and cross-project writeback;
- explicitly cross-project evidence is excluded before ranking and packing; and
- CI enforces both the release-candidate minima and the frozen 0.7.5 baseline without automatically
  rewriting either file.

## Frozen result

The six-case 1.0.0 suite freezes recall@5 `1.00`, MRR `1.00`, relevant fixture source coverage
`1.00`, wrong-project retrieval `0`, wrong-project writeback `0`, and Boron-owned LLM calls `0`.

## Verification scope

The release gate includes the standalone evaluation, Node/TypeScript tests and build, formatting,
production dependency audit, plugin payload validation, native Swift tests/build, package dry-run,
and the existing temporary PostgreSQL fixtures. The offline suite never reads production data.

## Remaining release-candidate gates

The live selected-evidence source-estimate coverage target, isolated
new-install/upgrade/uninstall/rollback drill, formal release checklist, and complete privacy,
retention, recovery, and support documentation remain open. Passing a six-case fixture suite is not
equivalent to product readiness.
